# PALINODIA（パリノディア）Physics Prototype 0.1

**実際に操作できるUnity 3D研究施設デモ**です。キャラクター、物理オブジェクト、2機の追跡ドローン、熱源、エネルギー操作、脱出ゲートが含まれます。ゲーム画面はUnity標準のプリミティブで実行時に自動生成するため、追加アセットは不要です。

**現状:** コード・Unityシーン・編集モードのテストを実装済み。ただしこの環境にはUnity Editorがないため、**Unityでのコンパイルと実動作は未検証**です。起動後にConsoleエラーが出た場合は、そのまま貼り付けてもらえれば修正できます。

## 初回起動

1. [Unity Hub](https://unity.com/download) からUnity 6のEditorを準備します。ソースの基準は`6000.0.67f1`ですが、互換性のあるUnity 6なら再シリアライズで開ける場合があります。
2. ZIPを展開し、`PALINODIA`フォルダーを**Unity Hub → Add project from disk**で追加します。`Assets`、`Packages`、`ProjectSettings`が直下にあるフォルダーを指定してください。
3. `Assets/Scenes/PhysicsLab.unity`をダブルクリックして、Unityの**Play**ボタンを押します。
4. 再生時に研究施設が生成されます。Editor停止中にシーン上に床や敵が見えないのは仕様です。

## 操作

| キー | 内容 |
|---|---|
| `W A S D` | 三人称移動 |
| マウス移動 | カメラ回転 / 照準 |
| `Space` | ジャンプ |
| `E`長押し | 照準先から熱を吸収（約7m） |
| 左クリック | 運動エネルギーを放出し、剛体を押し飛ばす |
| 右クリック | 熱エネルギーを放出する |
| `Tab`長押し | 物体の温度・稼働状態をスキャン |
| `R` | ステージをやり直す |
| `Esc` | マウスカーソルを解放 |

オレンジの**HEAT CORE**に照準を合わせて`E`を長押しするとエネルギーが溜まります。そのエネルギーを使い、**2機のドローン**を熱による電子機器の停止、または強い衝撃によって無力化します。2機とも止まると研究室奥の赤いゲートが開き、出口リングまで移動すればクリアです。

## 物理モデルの範囲

単純なHP式ではなく、共通の室温・各物体の熱容量と温度・有限のエネルギー蓄積・熱損失・剛体運動・機械の停止条件を扱っています。放出先の物体間でエネルギーが重複配分されないようにしています。反作用の運動量、物体破壊、電気、気圧波、人体の精密な物理などはまだ未実装です。詳しくは`Docs/PHYSICS_DESIGN.md`を参照してください。

## GitHubへ公開

GitHub接続からは既存リポジトリへの書き込みはできますが、この実行環境では**新規リポジトリを作る権限に対応する操作がありません**。そのため、完成したローカルGitリポジトリをZIPに同梱しています。GitHubで`palinodia`という**空の**リポジトリを作成してから、展開したフォルダーのターミナルで以下を実行してください。

```powershell
git remote add origin https://github.com/yamato0816/palinodia.git
git push -u origin main
```

GitHub上でリポジトリ作成が済めば、以後は接続済みGitHub経由でブランチやPull Requestを利用した更新を進められます。
