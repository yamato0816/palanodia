# 0.2 吸収ターゲット・演出仕様

## 修正した事象

以前はカメラ中央の `Physics.RaycastAll` が返す **最前面のColliderひとつ** から対象を決定していた。そのため、熱源の台座・ガードに照準を奪われると `AimedBody` が null になり、`E`長押しが無反応になった。

0.2では吸収対象の選択を攻撃対象とは分離した。`AbilityController` が現存 `PhysicalBodyState` をカメラ投影位置と視線で選び、熱源を軽く優先する。周辺の熱源が視界に入り、7.5 m以内かつプレイヤー胸から遮蔽がない場合にだけ `EnergyTransfer.Absorb` を実行する。攻撃側は既存の遮蔽・射程判定を維持。

- 橙色のリングは吸収対象を検出しているが、距離などの条件を満たさない状態。
- 緑色のリングは吸収できる状態。`HOLD [E] TO ABSORB` を出す。
- 満タン時は `STORAGE FULL`。コアからの熱を消費しない。
- 吸収成功でのみ `AbsorptionVisual.Transfer` を呼び、**熱源 → 主人公**へ螺旋状ラインと粒子を流す。
- 吸収中は残量ゲージとは別に瞬間吸収レート kJ/s を表示。

## FXと物理の分離

- `EnergyTransfer`と`PhysicalBodyState`が唯一のエネルギー収支を決定。線・粒子・ライトは状態を表現するだけで、物理エネルギーを生成しない。
- `EnergyCoreVisual`: 常時オレンジの浮遊粒子、二層のリング、熱温度に追随するライト。
- `AbsorptionVisual`: インタラクト可能なソースのリング、3本の吸収ライン、移動粒子と胸の受電リング。
- `PulseVisual`: 熱／運動のそれぞれに異なる色・火花・二層の衝撃波・短いライトフラッシュ。
- `DroneVisual`: 赤い監視リング、青い排気粒子、機能停止時の火花。
- `DemoBootstrap`: 床・壁ネオンを生成。**装飾パーツにはColliderを付けない**。ステージの遮蔽物は従来通り有効。

## Unity上の検証が必要な点

1. 7.5m以内でコアを見ると Eプロンプトが出て、熱が実際に移る。
2. 台座やガードが中央のクロスヘアに入っても吸収できる。
3. 壁を隔てると吸収できない（遮蔽は無視しない）。
4. 物理計算の`EnergyTransfer`の収支はエディタテストで検証する。
5. Built-in Render Pipelineで粒子の透過や加算表示、光量、FPSを確認する。

**注意:** Unity Editorのコンパイル・実行はこの環境では未検証。動作に問題があれば最初のConsoleエラーを保存すること。
